Ideas for Video Downloader

Each idea comes with a preview built from the app’s own styles at real size. They are grouped by how much they help and how much they cost. None of them are in the app yet. They go beyond the A–F spec, so I’d only build the ones you pick.

Small, high value

Under a day each. No new dependencies.

Pick up the link from the clipboard

When the window comes to the front and the clipboard holds a video link, offer it under the field. Most downloads start with “copy link in browser, switch to app”, so this saves the paste step every time.

  • Effort small
  • Where Download tab
  • Note reads the clipboard only when the app is focused

Show the file size for each quality

The resolution menu currently lists only heights. yt-dlp already reports sizes when it fetches the details, so each option can show what you’ll get on disk. That makes it easy to pick 720p over 1080p on a long video.

  • Effort small
  • Where Download options
  • Note some sites report no size, so those show “size unknown”

Errors that fix themselves in one click

The Instagram error currently tells you to go to Settings. Instead, offer the fix right there: retry with the browser you’re logged in to. That browser is saved as the default for next time.

  • Effort small
  • Where error panel
  • Note lists only browsers that are installed

Bigger features

One to three days each. They change how the app gets used.

Trim before you download

Drag the in and out points on the timeline and download only that part. yt-dlp can fetch just a section, so a 2-hour stream doesn’t have to come down whole for a 20-second clip. This also puts the timeline, already the app’s signature, to real use.

  • Effort medium
  • Where Download options
  • Note cuts land on the nearest keyframe unless re-encoded
